| Token | Value | Usage |

| sm | 8px | Compact element spacing, card padding |
| md | 16px | Default element spacing, form gaps |
| lg | 24px | Section padding, card header |

## UI Considerations

> Populated by the ui-phase UI-consideration probe (Step 9.5) and lifted by plan-phase's
> `## UI Considerations` lift rule via the identical rule as SPEC `## Edge Coverage`. Shape-rooted UI *state*
> coverage (empty / loading / error / populated / partial / overflow / zero-one-many / long-text).
> Empty-state and error-state COPY live in `## Copywriting Contract` above — this section covers
> state coverage and REFERENCES those rows rather than restating the copy (de-dup).

Applicable state considerations resolved: 8 covered, 2 backstop, 0 unresolved

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | Media library grid | ✅ covered | Empty state renders "No media items yet. Upload your first file." |
| empty | Dashboard stats | ✅ covered | Stats show zero values; no empty state needed — zero is valid |
| loading | Login form submit | ✅ covered | Button shows "Signing in..." with disabled state during submission |
| loading | Dashboard stats | ✅ covered | Skeleton cards with pulse animation render while loading |
| error | Login form | ✅ covered | Error alert renders above form with role="alert" and aria-live="polite" |
| error | Dashboard stats | ✅ covered | Destructive-colored alert with "Could not load dashboard stats. Refresh the page to try again." |
| populated | Dashboard stats | ✅ covered | Four stat cards with icon, value number, and title link |
| zero-one-many | Media library items | 🧪 backstop | Grid adapts to 0, 1, or many items — visual test for single-item layout |
| overflow | Media library grid | 🧪 backstop | Long filenames truncate with ellipsis in grid thumbnails |
| long-text | Media library table list | ✅ covered | Table cells truncate with text-overflow: ellipsis |
