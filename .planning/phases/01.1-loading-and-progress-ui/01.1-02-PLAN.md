### Task 2.1: Create ToastProvider and useToast hook

<read_first>
- `apps/frontend/components/ui/alert-dialog.tsx` — Read to understand base-ui context/component wrapping pattern
- `apps/frontend/app/admin/blog-posts/page.tsx` — Read lines 90-94 and 305-315 to see the existing inline toast prototype (auto-dismiss timeout, fixed positioning, green styling)
</read_first>

<action>
Create `apps/frontend/components/ui/toast.tsx` with the following exports:

**Type definitions:**
- `ToastVariant` type: `'success' | 'error' | 'info'`
- `Toast` interface: `{ id: number; message: string; variant: ToastVariant }`
- `ToastContextValue` interface: `{ showToast: (message: string, variant?: ToastVariant) => void }`

**ToastProvider component (`function ToastProvider({ children }: { children: React.ReactNode })`):**
- Creates `ToastContext` via `createContext<ToastContextValue | null>(null)`
- Manages `toasts` state as `Toast[]`
- `showToast` callback: generates incremental `id` via module-level counter, appends toast to state. Auto-dismisses non-error toasts after 2000ms via `setTimeout`
- `dismiss` callback: filters toast by `id`
- Renders `ToastContext.Provider` wrapping children
- Below children, renders a toast container div:
  - `fixed bottom-6 right-6 z-[9999]` positioning
  - `flex flex-col gap-2` for stacked layout
  - `aria-live="polite"` and `aria-atomic="false"` for accessibility
- Each toast:
  - `role="status"` for screen readers
  - Base classes: `flex items-center gap-2 rounded-xl px-4 py-3 text-sm text-white shadow-lg`
  - Animation: `animate-[toastSlideIn_0.25s_ease]` (uses `toastSlideIn` from globals.css)
  - Variant classes: success → `bg-green-600`, error → `bg-destructive`, info → `bg-foreground`
  - `maxWidth: 320` via inline style
  - Inner span for message text
  - Dismiss button (X icon) always rendered; visually relevant for error toasts (persist until dismissed)
  - Dismiss button: X icon size 14, `aria-label="Dismiss"`

**useToast hook (`function useToast()`):**
- Reads `ToastContext` via `useContext`
- Throws `'useToast must be used within a ToastProvider'` if context is null
- Returns `{ showToast }`

**Module-level counter:**
```tsx
let toastId = 0;
```
</action>

<acceptance_criteria>

- Exports `ToastProvider`, `useToast`
- `showToast('Saved.', 'success')` auto-dismisses after 2 seconds
- `showToast('Error occurred.', 'error')` persists until user clicks dismiss
- Toast renders with correct variant styling (green/red/dark backgrounds)
- Toast container uses `aria-live="polite"` and individual toasts use `role="status"`
</acceptance_criteria>
