### Task 1.3: Create Spinner component

<read_first>
`apps/frontend/components/ui/button.tsx` — Read to understand Lucide icon usage pattern and component conventions
</read_first>

<action>
Create `apps/frontend/components/ui/spinner.tsx`:

- Requires `"use client"` directive (uses Lucide icon)
- Function component `Spinner` with props: `{ size?: 'sm' | 'default' | 'lg', className?: string }`
- Size map: `{ sm: 14, default: 20, lg: 28 }`
- Wraps `LoaderCircle` from `lucide-react` in a `<span role="status">`
- Icon gets `aria-hidden="true"` and `animate-spin` class
- Includes `<span className="sr-only">Loading...</span>` for screen readers
- Size defaults to `'default'`
- Export named function `Spinner`

```tsx
'use client';

import { cn } from '@/lib/utils';
import { LoaderCircle } from 'lucide-react';

interface SpinnerProps {
  size?: 'sm' | 'default' | 'lg';
  className?: string;
}

const sizeMap = { sm: 14, default: 20, lg: 28 };

function Spinner({ size = 'default', className }: SpinnerProps) {
  const px = sizeMap[size];
  return (
    <span role="status">
      <LoaderCircle
        className={cn('animate-spin', className)}
        size={px}
        aria-hidden="true"
      />
      <span className="sr-only">Loading...</span>
    </span>
  );
}

export { Spinner };
```
</action>

<acceptance_criteria>
- File exists at `apps/frontend/components/ui/spinner.tsx`
- Has `"use client"` directive
- Uses Lucide `LoaderCircle` icon
- Supports `sm` (14px), `default` (20px), `lg` (28px) sizes
- Has `role="status"` on wrapper and `sr-only` "Loading..." for screen readers
- Can be imported as `import { Spinner } from '@/components/ui/spinner'`
</acceptance_criteria>
