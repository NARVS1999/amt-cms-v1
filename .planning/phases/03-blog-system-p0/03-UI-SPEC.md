## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge inner padding |
| sm | 8px | Compact element spacing, gap between inline buttons |
| md | 16px | Default element spacing, form field gaps, card padding |
| lg | 24px | Section padding, card internal spacing |
| xl | 32px | Layout gaps, section separators |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing (top/bottom of sections) |

Exceptions: none — all values are multiples of 4.

---

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 28px | 700 (bold) | 1.2 |
| Display | 36px | 700 (bold) | 1.1 |

- **Admin body:** 14px at weight 400 (inherited from shadcn/ui Card/Input/Table patterns — consistent with existing admin pages).
- **Admin heading:** 24px at weight 700 (matches existing `text-2xl font-bold` on admin page titles).
- **Public body:** 16px at weight 400, line-height 1.5 (matches existing public site).
- **Public heading:** 28px at weight 700, line-height 1.2 (matches existing `text-3xl font-bold`).
- **Blog post body (public):** Uses 16px body size at line-height 1.7 (enhanced for readability on long-form content). Max-width 720px.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` / `#f5f5f9` | Background surfaces. Public: white. Admin: `--surface` (#f5f5f9). |
| Secondary (30%) | `#1e1b2e` / cards | Admin sidebar. Cards use white on both surfaces. `--color-admin-card` (#ffffff) for admin card fills. |
| Accent (10%) | `#FF0000` | Primary CTA buttons, active nav indicator, "Published" badge highlight, "New Blog Post" button, Quill editor link/image toolbar icons. |
| Destructive | `#ef4444` | Delete buttons only — admin "Del" button, delete confirmation dialog. |

Accent reserved for:
- Primary CTA buttons (both surfaces)
- Active navigation indicator (underline or bg on current page)
- Status badge for "Published" state background
- Quill editor toolbar icon highlights on hover

**Additional tokens (existing, reuse as-is):**
- `--color-muted` (#f5f5f5) — alternate section backgrounds (public), placeholder image backgrounds
- `--color-border` (#f0f0f0) — card borders, dividers
- `--color-success` (#22c55e) — auto-save "Saved" indicator text
- `--color-error` (#ef4444) — same as destructive
- `--color-status-published-bg` (#dcfce7) / `--color-status-published-text` (#166534) — published badge
- `--color-status-draft-bg` (#f3f4f6) / `--color-status-draft-text` (#6b7280) — draft badge

### /blog Listing Page Layout

- Page: `app/(public)/blog/page.tsx` — SSG (`output: 'export'`)
- Heading: "Blog" — `text-3xl font-bold text-center`
- Grid: `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-8` — responsive
- Each cell: `BlogCard` component
- Pagination: 15 posts per page (per D-09). If >15 posts, SSG build fetches all pages in a loop.
- Empty state: "No posts published yet." — centered, `text-muted-foreground`

### Admin Table Changes

**Existing columns (keep):** Title, Author, Status, Image, Published At, Updated, Actions

**New/modified columns:**
- **Title + Excerpt** — Title stays. Below title, show truncated excerpt (max 80 chars, gray text, `text-sm text-muted-foreground`). Per D-19.
- **Sort Order** — Add column with up/down arrow buttons (Lucide `ChevronUp` / `ChevronDown`). Per D-17. Column goes between Image and Published At.
- **Reading Time** — Not a table column. Shown in modal form only, below Quill editor. Per D-15.

**Sort order buttons:**
- Icon buttons: `ChevronUp` and `ChevronDown` from Lucide
- Size: `size={14}` (small)
- Style: `text-muted-foreground hover:text-foreground`
- Top button disabled when first row. Bottom button disabled when last row.
- Action: calls API to swap `sort_order` values with adjacent post

### Auto-Save Indicator

- Location: Below form actions bar (after Save/Cancel buttons), right-aligned
- Text: `text-xs text-muted-foreground`
- States:
  - "Last saved: just now" — within 1 minute of last save
  - "Last saved: {N} minutes ago" — after 1 minute
  - "Unsaved changes" — when content differs from last saved (text in `var(--color-error)` / `#ef4444`)
- Updates every 30 seconds (matches existing auto-save interval)

### Reading Time Estimate

- Location: Below Quill editor, above Excerpt field
- Text: `text-sm text-muted-foreground`
- Format: "{N} min read" (e.g., "3 min read", "1 min read")
- Calculation: `Math.ceil(content.replace(/<[^>]*>/g, '').split(/\s+/).length / 200)`
- Updates on content change (debounced 500ms)

### SEO Implementation

- `generateMetadata()` in `/blog/[slug]/page.tsx` (Next.js App Router)
- `title`: `{post.title} | Adsvance Media Tech`
- `description`: Auto-generated from excerpt (first 160 chars of stripped HTML). Fallback: first 160 chars of content.
- `og:title`: `{post.title}`
- `og:description`: Same as meta description
- `og:image`: Post's featured image URL. Fallback: site logo or default OG image.
- `og:type`: "article"
- `article:published_time`: `{post.published_at}`
- `article:author`: "Admin"
