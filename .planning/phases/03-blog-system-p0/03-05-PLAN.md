# Plan 03-05: Blog System Sort Order Fix

## Goal

Fix the sort order swap functionality so posts can be reordered without errors. The issue is that existing posts may have sort_order = 0 (database default), causing the swap logic to fail when looking for neighbors.

## Gap Addressed

| Gap | Severity | Root Cause | Fix |
|-----|----------|------------|-----|
| G-03-SORT | major | All BlogPosts have sort_order = 0 (database default), neighbor lookup fails | Add migration to reset sort_order values + make swap more robust |

## Fix Steps

### Step 1: Migration to Reset Sort Order Values

**File:** `apps/backend/database/migrations/2026_07_26_000001_fix_blog_post_sort_order.php`

Create a new migration that:
1. Fetches all blog posts ordered by `created_at asc`
2. Assigns sequential sort_order values (1, 2, 3, ...)
3. This ensures existing posts have proper unique sort_order values

```php
<?php

use Illuminate\Database\Migrations\Migration;
use Illuminate\Support\Facades\DB;

return new class extends Migration
{
    public function up(): void
    {
        $posts = DB::table('marketing_blog_posts')
            ->orderBy('created_at', 'asc')
            ->get();

        foreach ($posts as index => $post) {
            DB::table('marketing_blog_posts')
                ->where('id', $post->id)
                ->update(['sort_order' => $index + 1]);
        }
    }

    public function down(): void
    {
        // Reset all to 0 (original default)
        DB::table('marketing_blog_posts')->update(['sort_order' => 0]);
    }
};
```

**Verify:** Run `php artisan migrate` — migration completes without errors.

### Step 2: Fix swapSortOrder to Handle Edge Cases

**File:** `apps/backend/app/Http/Controllers/Api/BlogPostController.php`

Update the `swapSortOrder` method to handle cases where:
1. Posts have the same sort_order (use `<=` instead of `<` for moving up)
2. The post is at the boundary (first/last position)

The current logic:
```php
$neighbor = BlogPost::where('sort_order', $direction === -1
    ? '<' : '>', $currentOrder)
    ->orderBy('sort_order', $direction === -1 ? 'desc' : 'asc')
    ->first();
```

Should be updated to also check for posts with the same sort_order but different ID:
```php
$neighbor = BlogPost::where('sort_order', $direction === -1
    ? '<=' : '>=', $currentOrder)
    ->where('id', '!=', $blogPost->id)
    ->orderBy('sort_order', $direction === -1 ? 'desc' : 'asc')
    ->first();
```

**Verify:** Run `php artisan test --filter=BlogPost` — tests pass.
