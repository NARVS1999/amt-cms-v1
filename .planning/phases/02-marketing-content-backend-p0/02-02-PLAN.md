   ```php
   public function reorder(Request $request)
   {
       $request->validate(['ids' => 'required|array', 'ids.*' => 'integer|exists:marketing_services,id']);
       foreach ($request->ids as $i => $id) {
           Service::where('id', $id)->update(['sort_order' => $i]);
       }
       return $this->success(['message' => 'Reordered.']);
   }
   ```

   Route::post('/pricing-plans/reorder', [PricingPlanController::class, 'reorder']);
   Route::post('/admin/pages/reorder', [PageController::class, 'adminReorder']);

2. In the Sort column cell, replace plain `{item.sort_order}` with a flex container showing the number plus up/down icon buttons.
3. Add `moveItem(index, direction)` handler to each page:
   ```typescript
   async function moveItem(index: number, direction: 'up' | 'down') {
     const target = direction === 'up' ? index - 1 : index + 1;
     if (target < 0 || target >= items.length) return;
     const newItems = [...items];
     [newItems[index], newItems[target]] = [newItems[target], newItems[index]];
     setItems(newItems);
     try {
       await reorderXxx(newItems.map(i => i.id));
       showToast('Reordered.', 'success');
     } catch (e: any) {
       showToast('Reorder failed', 'error');
       await load(); // reload to reset order
     }
   }
   ```
4. Disable Up on first item (`opacity-50 pointer-events-none`), Down on last item.
5. For **pages page**: Add Sort column header between Status and Actions columns (the table currently has Title, Slug, Status, Actions). Add Sort column cell with up/down controls.
