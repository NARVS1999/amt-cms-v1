**Goal:** End-to-end slice delivering team member photo upload/remove via dedicated endpoints (keep `store()` JSON-only) and the missing pricing-plans admin route. Covers backend controller changes, new API routes, SPEC update, frontend UI, and feature tests.

### Task 1: Add dedicated photo endpoints to TeamMemberController (JSON-only store)

<read_first>
- apps/backend/app/Http/Controllers/Api/TeamMemberController.php
- apps/backend/app/Models/TeamMember.php
- apps/backend/app/Http/Resources/Api/TeamMemberResource.php
- apps/backend/app/Http/Controllers/Api/BlogPostController.php (reference: Spatie file upload in store)
</read_first>

<action>
1. **Keep `store()` JSON-only.** Remove any photo validation/handling. The current `$request->validate()` stays as-is (name, role, bio, social_links, sort_order). No photo field.
2. **Keep `update()` JSON-only.** No photo handling. Update remains unchanged.
3. Add `removePhoto(TeamMember $teamMember)` method:
   ```php
   public function removePhoto(TeamMember $teamMember)
   {
       $teamMember->clearMediaCollection('photo');
       return $this->success(new TeamMemberResource($teamMember->load('media')));
   }
   ```
4. Add `uploadPhoto(Request $request, TeamMember $teamMember)` method:
   ```php
   public function uploadPhoto(Request $request, TeamMember $teamMember)
   {
       $data = $request->validate([
           'photo' => 'required|file|mimes:jpeg,png,webp',
       ]);
       if ($teamMember->getFirstMedia('photo')) {
           return $this->error('Remove existing photo first', 422);
       }
       $teamMember->addMediaFromRequest('photo')->toMediaCollection('photo');
       return $this->success(new TeamMemberResource($teamMember->load('media')));
   }
   ```
</action>

<acceptance_criteria>
- `POST /api/team` with JSON body (no photo) → 201 with `photo_url: null`
- `PUT /api/team/{id}` — does NOT accept photo; existing photo_url unchanged
- `DELETE /api/team/{id}/photo` → 200 + TeamMemberResource with `photo_url: null`
- `POST /api/team/{id}/photo` with file → 200 + TeamMemberResource with `photo_url` set
- `POST /api/team/{id}/photo` when photo already exists → 422 `"Remove existing photo first"`
- `POST /api/team/{id}/photo` without file → 422 validation error
- All responses use `$this->success(new TeamMemberResource(...))` per ApiResponse pattern
- `php artisan test --filter=TeamMembersTest` passes
</acceptance_criteria>
