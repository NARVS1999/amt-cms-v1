### Task 3.1: Create RouteChangeLoader component

<read_first>
- `apps/frontend/components/admin/sidebar.tsx` — Read to understand the admin component pattern (usePathname, useRouter usage, client component conventions)
- `apps/frontend/app/admin/layout.tsx` — Read lines 55-57 to see where `<main>` wraps `{children}` (the insertion point for RouteChangeLoader)
</read_first>

<action>
Create `apps/frontend/components/admin/route-change-loader.tsx`:

- `"use client"` directive (uses `usePathname` hook)
- Function component `RouteChangeLoader` accepting `{ children: React.ReactNode }`
- Uses `usePathname()` from `next/navigation`
- Uses `useRef` to track previous pathname
- Uses `useState<boolean>(false)` for overlay visibility

**Route change detection logic:**
```tsx
const pathname = usePathname();
const prevPath = useRef(pathname);
const [visible, setVisible] = useState(false);

useEffect(() => {
  if (prevPath.current !== pathname) {
    prevPath.current = pathname;
    setVisible(true);
    const timer = setTimeout(() => setVisible(false), 400);
    return () => clearTimeout(timer);
  }
}, [pathname]);
```

**Render:**
- Outer wrapper div with `position: 'relative'` and `minHeight: 'inherit'`
- When `visible` is true, render an overlay div:
  - `absolute inset-0 z-[100]` — covers only the relative parent (content area)
  - `flex flex-col items-center justify-center gap-6`
  - `bg-white/90 transition-opacity duration-300` — semi-transparent white fade
  - `aria-hidden="true"` — decorative only, not announced by screen readers
  - Inside overlay: flex container with `gap-2` holding 3 `<span>` elements (12px circles)
  - Each span: `h-3 w-3 rounded-full bg-[--color-primary]` (brand red)
  - Each span has inline `style` with `animation: 'dotBounce 1.2s ease-in-out infinite'` and staggered `animationDelay` of `0s`, `0.2s`, `0.4s`
  - Below dots: `<span className="text-sm font-medium text-muted-foreground">Loading</span>`
- Children rendered below the overlay (children always in DOM, overlay overlays on top)

The overlay covers the content area only — the sidebar remains visible and interactive during navigation.
</action>
