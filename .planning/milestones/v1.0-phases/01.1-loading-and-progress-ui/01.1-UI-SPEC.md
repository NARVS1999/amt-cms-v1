### Loading Component Specifications

#### 1. Skeleton Component (`components/ui/skeleton.tsx`)
- New shadcn-inspired component: `<Skeleton className="w-full h-4" />`
- Uses `animate-pulse` + `bg-muted` rounded styling (matches existing pattern in dashboard and media pages)
- Base styling: `rounded-md bg-muted animate-pulse`
- No ARIA needed (decorative)

#### 2. Spinner Component (`components/ui/spinner.tsx`)
- New component using Lucide `LoaderCircle` icon with `animate-spin` class
- Sizes: `sm` (14px), `default` (20px), `lg` (28px)
- Color inherits from current text color by default, accepts `className`
- ARIA: `aria-hidden="true"` with `sr-only` "Loading..." for screen readers

#### 3. Progress Bar (`components/ui/progress.tsx`)
- Import from shadcn registry (base-nova style)
- Used for upload progress in media page and future multi-step forms
- Consistent with shadcn/base-nova Progression component

#### 4. Page Transition Indicator
- Top bar: fixed, z-50, 3px height, `bg-primary`
- Animates: width 0% → 90% rapidly, then holds until route change completes, then 90% → 100% → fade out
- Only for admin panel (SPA-style navigation)
- `aria-hidden="true"` — decorative only

#### 5. Toast / Status Component
- Fixed bottom-right position (matches current blog auto-save toast at `fixed bottom-4 right-4`)
- Variants: success (green), error (red), info (muted)
- Auto-dismiss after 2s for success, manual dismiss for error
- Uses `<div role="status" aria-live="polite">` for accessibility

#### 6. Inline Error Banner
- `<div className="rounded-md bg-destructive/10 p-3 text-sm text-destructive" role="alert">`
- Already used consistently across login, forgot-password, dashboard, and media pages
- Standardize as shared sub-pattern (optional component)

#### 7. Suspense Boundary
- Wraps async data sections in admin pages
- Fallback uses Skeleton component matching the section's layout
- `React.Suspense` boundary at page section level (not full page — avoids layout shift)
