- Use a simple blade view or markdown mailable — keep it minimal

**Step 2: Create SendContactNotificationJob**

Create `apps/backend/app/Jobs/SendContactNotificationJob.php`:
- Class implements `ShouldQueue`
- Uses `Dispatchable`, `InteractsWithQueue`, `Queueable`, `SerializesModels` traits
- Property: `public ContactMessage $contactMessage`
- Constructor accepts ContactMessage
- `handle()` method: `Mail::to(config('contacts.notification_email'))->send(new ContactNotificationMail($this->contactMessage))`
- Add `failed()` method that logs the failure
- Set `$tries = 3` per NFR-7 (email retry: 3 retries, DB queue)
- Set `$backoff = 60` (60 seconds between retries)
