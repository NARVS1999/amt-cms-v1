# Sketch 002: Page Transition Overlay

## Design Question
What should the page transition loading overlay look like when navigating between admin pages?

## How to View
open .planning/sketches/002-page-transition/index.html

## Variants
- **A: Centered Spinner** — Semi-transparent overlay with a spinning indicator. Minimal, familiar, fast.
- **B: Branded Dots** — Overlay with three bouncing dots in primary (#FF0000). Playful, polished, feels alive.
- **C: Skeleton Overlay** — Content area skeletonizes with stat card and table row shapes. Feels faster by showing structure.

## What to Look For
- Click "Toggle Loading Overlay" on each variant to see the animation
- Which overlay feels most natural for page transitions?
- Does the spinner feel too plain vs the branded dots?
- Does the skeleton overlay feel more useful or more visually busy?
