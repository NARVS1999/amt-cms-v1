# Sketch 001: Skeleton Loading Variants

## Design Question
How should skeleton loading states feel across admin panel components — tables, stat cards, and lists?

## How to View
open .planning/sketches/001-skeleton-loading/index.html

## Variants
- **A: Pulse** — Gentle opacity fade (1.8s). Subtle, polished, eye-friendly.
- **B: Shimmer** — Sweeping highlight overlay (1.5s). Premium feel, more visually active.
- **C: Minimal** — Static skeleton blocks, no animation. Fastest perceived performance.

## What to Look For
- Which animation feels most polished without being distracting?
- Do the skeleton shapes accurately communicate what content will appear?
- Does the animation speed feel right for repeated use?
